# 当前验证信息

统一比较条件：5 个 demo、每个 120 帧，2K、30fps。渲染参数和原始统计来自已有四轮记录。

| 轮次 | 外观/采样变化 | 五例总耗时 |
|---|---|---:|
| 1（选定） | 64/16，阈值 0.01，OIDN | 82.22 分钟 |
| 2 | 128/64，阈值 0.005，头发调整 | 100.99 分钟 |
| 3 | 第二轮采样，头发 coat 调整 | 100.57 分钟 |
| 4 | 第三轮基础上 metallic 调整 | 104.97 分钟 |

这些是有限五例观察，不代表第一轮在任意人物上绝对最优。额外重试和已暂停的 4K 试验不计入上述时间。

新增裙骨适配和严格交叉检查后，一个 120 帧样例在匹配最终细分设置时检查耗时约 114–117 秒（当时两项 CPU 验证并行），不是全库平均。该样例的正面可见穿模改善，但仍存在内部交叉，因此被正式入口阻断。后续另一个 120 帧样例通过了全帧衣物检查。

六机位诊断：两个样例、每个三机位、每机位第 1/40/80 帧，共 18 张 2K 图。动作处理、检查及渲染共 616.06 秒。halfbody 偏膝上；头发近景暴露了粗卷发束和后侧偏暗。诊断输出没有写入正式完成队列。

旧版容量估算：1,908 项共 399,900 帧；按早期实测含预检约 11.06 秒/帧估计约 51.2 单 GPU 天，含 30% 余量约 66.6 天；输出存储约 81.1 GiB，含余量约 105.5 GiB。**这些估算不含新衣物检查、缺失素材补齐、未支持人物适配及重试，不能当作当前全量交付承诺。**
